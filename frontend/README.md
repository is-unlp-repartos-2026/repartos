# Siger

# OBJETIVO: RECREACIÓN VISUAL DE ALTA FIDELIDAD

Quiero que recrees visualmente la página web https://transportemorabito.com.ar/ con la mayor fidelidad estética posible.

IMPORTANTE: Este proyecto es exclusivamente visual. NO necesito funcionalidades, lógica de negocio, backend ni integraciones.

La página resultante debe ser una reproducción visual muy cercana a la referencia, no una reinterpretación creativa ni una plantilla genérica de una empresa de transporte.

## 1. ANÁLISIS DE LA REFERENCIA

Antes de escribir código, inspeccioná visualmente la página original.

Analizá:
- La estructura completa, desde el encabezado hasta el footer.
- La distribución de todos los elementos.
- Las tipografías, pesos, tamaños y alturas de línea.
- Los márgenes, paddings, espacios y anchos de contenido.
- Las proporciones de las imágenes.
- Los fondos, bordes, separadores y sombras.
- La alineación de los títulos, textos, imágenes e iconos.
- La cantidad de contenido que entra en cada sección.

Si podés inspeccionar el código fuente, los estilos CSS y los recursos originales, utilizalos para obtener medidas y propiedades visuales más precisas.

Si no podés acceder visualmente a la página, solicitame capturas de pantalla antes de tomar decisiones importantes sobre el diseño.

## 2. REPRODUCCIÓN DE LA ESTRUCTURA

Recreá todas las secciones presentes en la referencia y respetá su orden original.

Incluí el encabezado, la navegación, el hero, los bloques informativos, las tarjetas, los servicios, la cobertura geográfica, las sucursales, las llamadas a la acción y el pie de página, siempre que estén presentes en la página original.

No inventes secciones nuevas ni elimines secciones existentes.

## 3. FIDELIDAD ESTÉTICA

La prioridad absoluta es la similitud visual.

Reproducí con precisión:
- Las dimensiones relativas de cada sección.
- Los anchos de los contenedores.
- Las columnas y sus proporciones.
- Las alturas y alineaciones.
- La jerarquía tipográfica.
- Los colores de fondo y de texto.
- Los espacios entre elementos.
- Los estilos de botones y enlaces.
- Los bordes, separadores y radios de esquina.
- Las imágenes y sus recortes.
- La densidad visual y la cantidad de información.

## 4. IMÁGENES, ICONOS Y TIPOGRAFÍAS

Utilizá los recursos visuales originales cuando estén disponibles y su uso esté autorizado.

Si no están disponibles, buscá alternativas visualmente similares en temática, composición, iluminación y proporciones.

Identificá las tipografías utilizadas y empleá las mismas cuando sea posible. Si no podés determinar cuál es la fuente original, elegí la alternativa más cercana.

Mantené las proporciones originales de los logotipos y las imágenes.

## 5. IMPLEMENTACIÓN

Construí exclusivamente el frontend visual utilizando HTML, CSS y, si hace falta, JavaScript mínimo para la presentación.

Si el entorno requiere React, utilizá React con componentes reutilizables y estilos CSS.

Separá el código por secciones para facilitar modificaciones posteriores.

Todos los botones, enlaces, menús, formularios y campos deben existir únicamente como elementos visuales.

No implementes:
- Backend.
- Bases de datos.
- Autenticación.
- Envío real de formularios.
- Integraciones con WhatsApp.
- APIs.
- Lógica de negocio.
- Sistemas de seguimiento.
- Procesamiento de cotizaciones.

Los elementos que parecen interactivos pueden ser estáticos. Dejá el código organizado para que yo pueda programar su comportamiento posteriormente con otro lenguaje.

## 6. RESPONSIVE

Reproducí la apariencia original tanto en escritorio como en dispositivos móviles.

Utilizá CSS responsive y media queries para adaptar la composición a diferentes anchos de pantalla.

No deformes las imágenes ni permitas desbordamientos horizontales.

## 7. CONTROL VISUAL

Cuando termines la primera versión, ejecutala y comparala visualmente con la referencia.

Corregí las diferencias más importantes en este orden:

1. Estructura general y dimensiones.
2. Encabezado y navegación.
3. Sección principal y fotografías.
4. Distribución de las columnas y tarjetas.
5. Tipografía, colores y espaciados.
6. Secciones inferiores y footer.
7. Versión móvil.

No consideres terminado el trabajo simplemente porque la página se vea profesional.

Consideralo terminado cuando la composición visual sea lo más fiel posible a la referencia.

Si no podés inspeccionar una característica o comparar capturas, indicá esa limitación en lugar de afirmar que la verificaste.
